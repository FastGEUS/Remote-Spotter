# Сервер Remote Spotter 0.4.12

Публичный код обновлён до состояния сервера 0.4.11. В него входят улучшения
обработки iRacing, список «до пяти выше — пилот — до пяти ниже», компактная
компоновка, удаление постоянных пояснений под блоками и исправление их высоты.
Карта получает полный доступный состав машин; пояснения доступны при наведении.

В 0.4.12 исправлены русские подписи и подсказки. «Возраст данных» обозначает
возраст показанного результата с момента приёма его кадра на сервере.
«Остаток» у шины — оставшийся протектор, усреднённый по трём зонам.
У шин iRacing явно указан замер в боксах.

Клиенты 0.6.9 и 0.6.10 совместимы. Для изменений веб-панели достаточно
обновить сервер и снова открыть окно споттера. Текущие исходники клиентов
0.6.11 также содержат новые подписи подключения и исправление SDK из 0.6.10.

Изменения исходников на GitHub не устанавливают обновление на VPS.
Сборка и установка сервера описаны в [deploy/remote/README.md](../../deploy/remote/README.md).
Для обновления существующей установки используйте полный пакет из
deploy/desktop/package-desktop.py. Пакет интерфейса package-ui.py подходит
только для уже обновлённого серверного расчёта и не заменяет модули Python.

В этой публикации нет готового серверного бинарника. Его нужно собрать
из relay/ для нужной архитектуры. Установщики не запускаются автоматически.
Результаты проверок: [TESTING.md](TESTING.md).
