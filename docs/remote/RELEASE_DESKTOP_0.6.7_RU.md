# Публичные клиенты Remote Spotter 0.6.7

Окно споттера скрывается до завершения фоновой очистки; фон браузера тёмный.
В обоих клиентах добавлено by Svet и ресурсы версии EXE.

Сервер 0.4.7. Эта исходная поставка не содержит готовых бинарников, токенов
или SSH-ключей. Первый запуск публичного клиента требует настройки доступа
к собственному VPS. Общие шаги находятся в корневом README.md.
Доверенная цифровая подпись EXE пока отсутствует.
