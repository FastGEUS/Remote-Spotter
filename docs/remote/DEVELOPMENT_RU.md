# Как устроен Remote Spotter и что проверять дальше

Актуальные исходники: клиенты 0.6.11, сервер 0.4.12.

## Путь данных

SpotterPilot читает данные симулятора и отправляет снимки через SSH-туннель.
Сервер Go принимает их, запускает расчёты Python и передаёт результат панели
споттера. SpotterViewer открывает эту панель во встроенном браузере.

В LMU используются shared memory и дополнительные данные REST, когда они
доступны. Для LMU на сервере запускаются 12 модулей TinyPedal. Для iRacing
работает отдельный адаптер. Каталог из 76 панелей общий, но доступность
показателей различается: панель может работать частично, показывать замер
в боксах или не поддерживаться выбранной игрой.

Для iRacing клиент выбирает 129 названий каналов SDK и четыре раздела
SessionInfo: WeekendInfo, DriverInfo, SessionInfo и SplitTimeInfo.
Фактический набор каналов зависит от машины и сессии. YAML разбирается
на сервере. Приложение пилота запрашивает снимки с частотой 20 Гц; скорость
получения и обработки может снижаться под нагрузкой. Чтение IBT и Web Data API
в текущем коде не реализовано.

Подробное соответствие показателей источникам:
[IRACING_DATA_SOURCES.md](IRACING_DATA_SOURCES.md).
Формат обмена: [PROTOCOL.md](PROTOCOL.md).

## Как читать статусы

| Сообщение | Что означает | Что проверить |
| --- | --- | --- |
| Подключено | Клиент установил связь с сервером | Статус игры и свежесть телеметрии проверяются отдельно |
| Ожидание данных игры | Сборщик не получил пригодные данные симулятора | Загружена ли сессия; интерфейс выбора гонок iRacing сам по себе не даёт телеметрию |
| В гараже | Сессия обнаружена, пилот находится в гараже | Нормальное состояние перед выездом |
| На трассе / Данные поступают | Получены свежие данные движения | Сравнить показатели с игрой |
| Нет свежих данных | На экране остались старые значения | Запущен ли симулятор, обновляется ли SDK, работает ли серверный расчёт |
| Восстановление связи | Клиент повторно подключается к серверу | Сеть, SSH и состояние службы на VPS |

Возраст данных отсчитывается от приёма кадра на сервере. Он включает ожидание
расчёта и сам расчёт, но не измеряет весь путь от симулятора до экрана.
ingestAgeMs относится к последнему принятому кадру, sourceAgeMs — к кадру,
который использован для показанного результата. Малый ingestAgeMs не делает
старый результат свежим.

После закрытия симулятора iRacing сборщик освобождает старую память SDK.
При остановке счётчика кадров на 2,5 секунды также выполняется сброс;
повторная попытка подключения — примерно раз в секунду. Новая сессия
получает отдельный идентификатор. SSH при этом может оставаться подключённым.
Переход практика → выход → гонка проверяется отдельным тестом;
проверка в настоящем iRacing остаётся обязательным шагом перед гонкой.

## Ограничения текущей версии

- Сервер обслуживает одну комнату с одним источником телеметрии. Независимые
  команды, учётные записи и разделение нескольких комнат пока не реализованы.
- Таблица показывает до пяти машин выше пилота и до пяти ниже по общей
  позиции. Карта получает полный доступный состав.
- Карта iRacing строится по движению машины и может отличаться от геометрии
  трассы. Каталога готовых карт пока нет.
- Интервалы к пилоту и времена секторов iRacing рассчитываются приблизительно.
  Подтверждённой привязки локальных жёлтых флагов к секторам нет.
- Температура каркаса и остаток протектора iRacing отображаются как замеры
  в боксах. Сохранённое значение не подтверждает текущую температуру шины
  на трассе. Непрерывную температуру поверхности приложение не показывает.
- Основной блок шин показывает средний остаток по трём зонам. Среднее может
  скрывать износ одной зоны; предупреждения по минимальному остатку ещё
  предстоит разработать.
- Нет подтверждённой модели прогноза износа, перегрева и автоматических
  рекомендаций по стилю езды. Ухудшение времени круга само по себе не доказывает
  проблему с шинами.

## Проверки без второго участника

Оба клиента можно запускать на одном компьютере. Для разработки не нужен
постоянный второй пилот: автоматические тесты используют демоданные,
синтетическую память SDK и локальное SSH-подключение.

1. Запустить Python, JavaScript и Go-тесты по [TESTING.md](TESTING.md).
2. Проверить весь путь от синтетического SDK до окна споттера через
   remote.tests.iracing_e2e. В тест входит смена сессии без перезапуска клиента.
3. Проверить интерфейс LMU на демоданных: карту, таблицу, флаги, шины,
   полноэкранный режим, CSV и переподключение.
4. На Windows собрать оба клиента и запустить их на одном ПК с разными
   ключами ролей. Сверить отсутствие обрезанных блоков и завершение процессов.
5. В настоящей игре проверить движение, гараж, пит-стоп и смену сессии.
   Это отдельная проверка: успешная имитация SDK её не заменяет.

## Следующие изменения и критерии проверки

| Приоритет | Доработка | Как понять, что работает |
| --- | --- | --- |
| 1 | Проверка смены сессий iRacing на Windows | Практика → выход → гонка восстанавливает свежие данные, трассу и состав без перезапуска SpotterPilot |
| 1 | Замеры шин и история комплектов | Заезд со сменой шин показывает, когда обновляются три зоны температуры и остатка; история не смешивает разные сессии |
| 1 | Каталог каналов реальной машины | Сохранены названия, типы, единицы и доступность каналов; дополнительные поля согласованы с проверкой на сервере |
| 2 | Чтение и воспроизведение IBT | Записанный файл даёт повторяемый результат; для чтения во время записи отдельно измерены задержка и доступность новых записей |
| 2 | Предупреждения по поведению машины | Сообщение опирается на конкретные педали, руль, скорость и условия; выводы об износе или перегреве помечены как оценки |
| 2 | Разделение чтения SDK и передачи по сети | Замерены пропуски кадров, нагрузка и задержка до и после правки; повышение частоты оправдано измерениями |
| 3 | Готовые карты через Web Data API | Контур выбран для правильной конфигурации трассы и сопоставлен с прогрессом машин; проверена авторизация |

Новые каналы сначала проверяются на записи настоящей сессии. Пороги
предупреждений задаются для конкретной машины и условий, а не единым числом
для всех автомобилей.
