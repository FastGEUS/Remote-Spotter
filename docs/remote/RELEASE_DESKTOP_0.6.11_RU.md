# Клиенты Remote Spotter 0.6.11

Публичные исходники приведены к состоянию последних персональных выпусков
0.6.8–0.6.10. Дополнительно исправлены русские статусы, сообщения настройки
и ошибок подключения. «Подключено» относится к связи с сервером;
«Ожидание данных игры» — к телеметрии симулятора.

Сохранено исправление 0.6.10: после выхода из iRacing сборщик освобождает
старую память и состояние SDK, затем подключается к новой сессии.
Изменение таблицы каналов, сброс счётчика и отсутствие новых кадров
также вызывают повторное открытие SDK. SSH не требуется перезапускать.

Для iRacing нужен сервер 0.4.8 или новее. Актуальный сервер этой публикации —
0.4.12; прежние серверы 0.4.9–0.4.11 совместимы. Споттер 0.6.9 совместим
с новым пилотом, но для новых подписей в самом клиенте его нужно пересобрать.

Для сборки Windows x64 запустите BUILD_WINDOWS.cmd из корня репозитория.
Нужен Python x64 3.11–3.13. Результат — dist/SpotterPilot и dist/SpotterViewer.
Передавайте папку выбранной роли целиком, включая _internal.
Готовые Windows EXE в этой публикации не предоставляются.

При первом запуске задайте адрес собственного VPS, пользователя SSH,
приватный SSH-ключ и ключ доступа выбранной роли. Публичная поставка
не содержит настроенного подключения к серверу разработчика.

Проверки и оставшиеся ограничения: [TESTING.md](TESTING.md).
Устройство приложения и план разработки: [DEVELOPMENT_RU.md](DEVELOPMENT_RU.md).
