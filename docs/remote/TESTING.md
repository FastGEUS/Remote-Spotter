# Проверки iRacing 0.6.0 / server 0.4.7

72 Python-теста и 23 JavaScript-теста прошли; `go test -race ./...` — успешно.
Парсер читает синтетическую бинарную память настоящим pyirsdk, проверяет
индексы игроков, номера с ведущими нулями, флаги, шины, неполные данные,
повреждённые кадры, реальное расположение отсечек, оценку топлива и кеш карты.

`remote.tests.iracing_e2e`: настоящий OpenSSH, два окна Qt, авторизация cookie,
WebSocket, iRacing-адаптер VPS, записанная карта, 76 карточек со статусами
поддержки, отключение партнёра и завершение обоих приложений. Linux offscreen,
синтетические SDK-байты; это не сессия живой игры.

Регрессия: `desktop_e2e` с LMU-протоколом демо и восстановлением туннеля;
`desktop_ssh_check` с двумя ролями, пробелами в путях и сменой ключа сервера;
`desktop_lifecycle_check` с реальными точками запуска, выходом, повторным
запуском, зависшим worker/GUI и остановкой принадлежащих приложению процессов.

Windows-сборку, Windows Job Object и живую iRacing/LMU здесь не проверяли.
План проверки после установки — в инструкции выпуска 0.6.0.
