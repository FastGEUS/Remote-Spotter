# Проверки Remote Spotter

Актуальные исходники: клиенты 0.6.11 / сервер 0.4.12.
Результаты относятся к публичной копии без персональных пресетов.

## Результаты проверки 2026-10-13

- Python: выполнены 115 тестов, ошибок нет; один тест Windows пропущен на Linux.
- JavaScript: все 25 тестов прошли.
- Go: test, vet и сборка Linux-бинарника прошли с CGO_ENABLED=0.
  Race detector в этой проверке не запускался.
- iRacing E2E: синтетическая память настоящего pyirsdk, реальный OpenSSH,
  оба окна Qt, 64 машины, замеры шин, пропуск повреждённого кадра и смена
  сессии без нового подключения — успешно.
- GUI и веб-панель: состояния подключения, вход, карта, компактная таблица,
  флаги, CSV, полный экран, дополнительные панели, desktop/mobile,
  устаревание и переподключение — успешно; ошибок JavaScript нет.
- Полный пакет и пакет интерфейса создаются из публичной копии. Проверены
  архивы, локальные ссылки документации и отсутствие персональных доступов.

Среда: Linux, Python 3.12, Node.js 24, Go 1.27.1, PySide6 6.8.3.
Все игровые данные в этих проверках синтетические. Windows EXE не собирались,
живые LMU/iRacing и пользовательский VPS в этой проверке не запускались.

## Автоматические проверки

Команды выполняются из корня репозитория. Для unit-тестов Python нужны
зависимости сервера и pyirsdk; Qt для них не требуется.

```bash
python -m pip install -r remote/requirements.txt pyirsdk==1.3.7
python -m unittest discover -s remote/tests -v
node --test remote/tests/*.test.cjs
cd relay
CGO_ENABLED=0 go test ./...
CGO_ENABLED=0 go vet ./...
CGO_ENABLED=0 go build -o spotter-relay .
```

В .github/workflows/tests.yml добавлен запуск Python, JavaScript и Go-тестов
при push и pull request. Проверки GUI в этот workflow не входят.

## Сквозная проверка SDK и клиентов

Для этих сценариев дополнительно нужны полный PySide6, asyncssh,
pyirsdk и установленный ssh. Выполните из корня репозитория:

```bash
python -m pip install PySide6==6.8.3 asyncssh pyirsdk==1.3.7
python -m remote.tests.iracing_e2e relay/spotter-relay
python -m remote.tests.desktop_gui_check relay/spotter-relay build/gui-check
```

На Linux без графической сессии задайте QT_QPA_PLATFORM=offscreen.
Особенности запуска Chromium зависят от среды. iRacing E2E создаёт временные
ключи и локальный SSH-сервер, затем проверяет синтетическую бинарную память
SDK, расчёт на сервере и оба окна приложения. В сценарий входит переход
практика → закрытие симулятора → новая гонка без нового SSH-подключения.

Для проверки веб-панели нужны Playwright и Chromium:

```bash
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node remote/tests/ui_smoke.cjs relay/spotter-relay
```

При наличии полного PySide6 вместо отдельного Chromium можно использовать
QtWebEngine: задайте SPOTTER_QT_BROWSER=1 перед запуском ui_smoke.cjs.
Сценарий проверяет компоновку, список вокруг пилота, карту, радар,
флаги, CSV, полный экран, устаревание и восстановление соединения.

## Что остаётся проверить в настоящих играх

| Сценарий | Ожидаемый результат |
| --- | --- |
| iRacing: практика → выход → гонка | Возобновляются свежие данные, новая трасса и состав, без перезапуска SpotterPilot |
| iRacing: заезд, пит-стоп и смена шин | Зафиксировано, когда меняются три зоны температуры и остатка; замеры не выдаются за live-датчики |
| iRacing: смена машины и конфигурации трассы | Кэш карты и замеров не смешивается между сессиями |
| LMU: гараж, выезд, питы, финиш | Показатели, сектора и флаги сверены с игрой |
| Потеря сети, туннеля и перезапуск сервера | Старые показания помечены; соединение и свежие данные восстанавливаются |
| Windows: сборка, запуск и закрытие обеих ролей | Открываются оба клиента; выход завершает принадлежащие им процессы |
| Длительный заезд на VPS | Измерены CPU, память, пропуски кадров и задержка; память не растёт без ограничения |

Нужны отдельные проверки на Windows и длительный заезд. Синтетический SDK
подтверждает работу нашего кода с заданными данными, но не доступность
каналов в конкретной машине. Повышение частоты до 60 Гц, чтение IBT
во время записи и автоматические предупреждения о перегреве пока не реализованы.
