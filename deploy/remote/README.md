# Сервер Remote Spotter

Сервер Go принимает телеметрию и отдаёт веб-панель. Расчёты выполняет Python.
Текущая версия — 0.4.12. Схема подключения: собственный Linux VPS,
SSH-туннели и внутренний адрес 127.0.0.1:8080.

## Первичная установка

Понадобятся Python с venv и pip, Go 1.24 или новее, OpenSSH Server и curl.
Скопируйте исходники из этого репозитория в /opt/tinypedal-remote.
Следующие команды выполняются в этой папке на VPS; путь рассчитан
на службу spotter.service из репозитория.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r remote/requirements.txt
cd relay
CGO_ENABLED=0 go build -o spotter-relay .
cd ..
sudo bash deploy/remote/install-local.sh
```

Сборка выполняется для архитектуры самого VPS. Если собираете на другой
машине, явно задайте подходящие GOOS и GOARCH. Установщик создаёт
системного пользователя и службу на сервере.

Установщик создаёт /etc/spotter/credentials.env с двумя разными ключами:
SPOTTER_PILOT_TOKEN и SPOTTER_VIEW_TOKEN. Передайте каждому участнику
ключ его роли через свой закрытый канал. Для SSH настройте отдельные
ключи участников и пользователя, которому разрешено перенаправление
на 127.0.0.1:8080. Доступ к серверу разработчика в поставку не входит.

В первом окне Windows-клиента укажите адрес VPS, пользователя SSH,
файл приватного SSH-ключа и ключ выбранной роли. Отпечаток SSH-ключа
сервера сверяется при первом подключении.

## Обновление существующей установки

Соберите relay/spotter-relay из текущих исходников. Из корня репозитория
создайте полный пакет:

```bash
python deploy/desktop/package-desktop.py --output remote-spotter-update.zip
```

Без --pair-profile пакет не содержит персональных пресетов.
Распакуйте его и перенесите папку server на VPS. В этой папке находятся
spotter-relay, source и update.sh. Запустите update.sh от root.
Полный установщик обновляет серверный расчёт и веб-панель, сохраняет
предыдущую версию и проверяет /healthz. Ключи доступа и данные
/var/lib/spotter сохраняются. При ошибке выполняется откат.

package-ui.py и update-ui.sh предназначены для обновления веб-панели
и бинарника на уже совместимой установке. Они не заменяют Python-модули.
При переходе со старого публичного сервера 0.4.7 нужен полный пакет.

Изменение файлов на GitHub само по себе не обновляет VPS.
После установки перезапустите окно споттера; в обычном браузере
обновите страницу с Ctrl+F5.

## Проверка

/healthz подтверждает доступность службы. Авторизованный /api/status
показывает версию, состояние источника, возраст принятых данных и время
расчёта. Успешный /healthz не подтверждает наличие свежей телеметрии игры.
