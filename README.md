# Remote Spotter

**Язык / Language:** **Русский** | [English](README_EN.md)

**Публичная бета · исходники для самостоятельного развёртывания**

**Удалённый пит-волл для iRacing и Le Mans Ultimate · by Svet**

Remote Spotter помогает пилоту и споттеру работать вместе, находясь в разных
сетях. Пилот запускает небольшое приложение, а споттер видит гоночную панель
в отдельном окне: позиции, состояние машины, топливо, флаги и доступные
показатели сессии. Демонстрацию экрана можно параллельно смотреть в Discord.

## Как это работает

1. Приложение пилота читает телеметрию запущенной игры через shared memory / SDK и отправляет исходные данные на ваш VPS.
2. VPS принимает данные, выполняет расчёты и отдаёт результаты панели споттера.
3. Приложение споттера отображает веб-интерфейс внутри собственного окна.
4. Оба приложения автоматически создают SSH-туннели к серверу. Домен для этой схемы не требуется.

Компьютер пилота выполняет чтение, упаковку и передачу данных; расчёты вынесены
на сервер. Отрисовка интерфейса выполняется на компьютере споттера. Программа
не передаёт видео и не заменяет Discord.

## Возможности текущей версии

- Минималистичное окно пилота: подключение, статус игры и присутствие споттера.
- Панель споттера с картой, позициями, флагами, топливом и состоянием машины.
- Данные секторов и сравнение там, где их поддерживает источник.
- Повторное подключение, диагностика и автоматическая подготовка прав SSH-ключа в Windows.
- Одновременный запуск приложений пилота и споттера на одном ПК.

Это развивающийся проект. Доступность показателей зависит от игры. Каталог
содержит 76 карточек, но это не означает, что все функции TinyPedal перенесены
или работают одинаково в обеих играх. В iRacing некоторые данные шин доступны
как снимки из питов, карта восстанавливается приблизительно, а вместо точного
радара соперников используется индикатор близости. Секторы iRacing вычисляются
приблизительно; локальные жёлтые флаги к секторам не привязываются.

Текущие версии: Windows-клиенты **0.6.7**, сервер **0.4.7**. Сервер рассчитан
на одну пару пилот–споттер / одну комнату. Многопользовательский сервис,
учётные записи и готовый каталог всех треков пока не реализованы.

## Windows Defender при первом запуске

**При первом запуске приложений и автоматической настройке SSH-подключения
Windows Defender может определить приложение или его вспомогательный компонент
как троян и заблокировать его либо поместить в карантин.** Такие срабатывания
наблюдались при тестировании; причина конкретного обнаружения требует проверки.

Исходный код доступен в этом репозитории: его можно изучить и самостоятельно
собрать приложение. Открытость кода сама по себе не гарантирует безопасность
конкретного EXE или его соответствие исходникам.

Если появилось уведомление:

1. Откройте **Безопасность Windows → Защита от вирусов и угроз → Журнал защиты**
   и проверьте название обнаружения и путь к файлу.
2. Если вы проверили происхождение сборки и уверены, что это ошибочное
   срабатывание именно на Remote Spotter, выберите **Действия → Разрешить
   на устройстве (Allow on device)** для этого обнаружения, чтобы Defender
   разрешил использование файла.
3. Если файл уже в карантине, при той же уверенности выберите **Восстановить**.
   Defender может обнаружить его повторно — тогда разрешение нужно подтвердить
   в журнале защиты.

Если уверенности нет, оставьте файл в карантине и отправьте его на
[проверку в Microsoft](https://www.microsoft.com/en-us/wdsi/filesubmission).
Порядок действий описан в
[справке Microsoft о журнале защиты](https://support.microsoft.com/en-us/windows/security/windows-security/protection-history-in-the-windows-security-app).

## Что потребуется сделать самостоятельно

1. Подготовить компьютеры участников и установить необходимые компоненты Windows.
2. Арендовать или использовать свой VPS с Linux и настроить доступ к нему.
3. Создать отдельные SSH-ключи и настроить разрешения для подключения приложений.
4. Собрать серверную часть, разместить её на VPS и запустить службу.
5. Получить отдельные ключи доступа приложения для пилота и споттера.
6. Собрать Windows-приложения из исходников и передать каждому участнику его папку.
7. Указать адрес своего сервера, нужный SSH-ключ и ключ соответствующей роли.
8. Проверить соединение и телеметрию в тестовой сессии перед гонкой.

Общие требования: Windows x64 для клиентов, Python 3.11–3.13 x64 для сборки,
OpenSSH Client для подключения, Linux/Python для VPS, Go 1.24 или новее для
сборки сервера. Для запуска собранных EXE установка Python не требуется.
Подробный авторский гайд для начинающих с командами и разбором ошибок
готовится для Boosty. Ссылка будет добавлена после публикации.

Код доступен открыто; платный материал — дополнительное руководство по
самостоятельной установке. Покупка руководства не требуется для использования
кода. Аренда VPS и доступ к игре оплачиваются отдельно. Доступ к серверу
разработчика в публичную версию не входит.

## Исходники и происхождение

`remote/` содержит сборщик, адаптеры игр, серверные расчёты и GUI клиентов;
`relay/` — сервер Go и веб-панель; `deploy/` — скрипты сборки и развёртывания.
В репозитории сохранены исходники TinyPedal и используемых shared memory библиотек.
Публичный код не содержит персональных токенов, SSH-ключей или настроенных
профилей доступа. При первом запуске публичного клиента открывается форма настройки.

Проект основан на [TinyPedal](https://github.com/TinyPedal/TinyPedal), версия
v2.50.0, commit `b6ef05a695686cd18e0b807cd8933fd91e813ad5`.
Для iRacing используется [pyirsdk](https://github.com/kutu/pyirsdk).
Версии источников зафиксированы в `remote/upstream-lock.json`.
Описание исходного TinyPedal сохранено в `UPSTREAM_README.md`.

Развитие удалённого подключения, GUI и панели Remote Spotter — **Svet**.
Авторы TinyPedal и сторонних библиотек сохраняют авторство своих компонентов.
Основной проект распространяется на условиях [GNU GPLv3](LICENSE.txt);
лицензии зависимостей сохранены в исходниках и материалах сборки.

Windows EXE пока не имеют доверенной цифровой подписи: SmartScreen может
показывать предупреждение об неизвестном издателе. Не размещайте в публичном
репозитории приватные ключи, токены, персональные сборки или журналы с доступами.

Ошибки и предложения можно оставлять в [GitHub Issues](https://github.com/FastGEUS/Remote-Spotter/issues). Укажите игру, версии клиента и сервера, Windows и последовательность действий. Журналы приложите после удаления токенов, ключей и личных данных. Индивидуальная установка и постоянная поддержка не входят в бесплатный доступ к исходникам.
